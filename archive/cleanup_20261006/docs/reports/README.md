# 检查报告

`ch01_*_check.json` 与 `menu_pages_check.json` 由对应工具或当轮核查产生。报告保留检查当时的事实，不把用户最终验收回填成 Agent 的引擎实测。

- 台本与导出：`ch01_static_check.json`、`ch01_build_check.json`。
- 图片与界面：`ch01_resource_check.json`、`ch01_expression_check.json`、`ch01_font_check.json`、`menu_pages_check.json`。
- 音频：`ch01_voice_check.json` 是 33 条配音导入核查；`ch01_audio_check.json` 是较早一轮音乐／音效接入报告，并非完整音频清单。
- 整理：`organization_moves.json` 是旧路径到新路径映射；`organization_check.json` 是最终引用与保全检查。

完整当前素材清单在 `assets/inventory.json`。本地运行文件摘要在 `docs/release/workspace_manifest.json`；发布状态在 [发布记录](../release/README.md)。
