## 现有立绘与未来差分

本轮沿用 1024×1536 现有立绘。启星显示约为原图 1.06 倍、千夏 0.96 倍，不需要为此次构图重新生成整个人物。原图不裁切、不覆盖，后续差分应以已确认的对应角色立绘为底图，固定画布、身体、衣服、发型轮廓和脸部位置，仅局部修改表情，叠合核对后接入。

如果后续近景实际验收认为脸部清晰度不足，再考虑制作更高清的统一底图，并同步迁移该角色全部差分；不要逐张独立生成新全身图，避免换表情时变脸、衣服漂移或身形跳动。

本轮由 Agent 做资源静态检查，最终构图由用户实际运行验收。重点查看街道两人同框、餐厅两人同框、千夏三种既有表情及马皙同框。
