## 配音交付边界

用户决定自行生产所有语音。Agent 提供 `voice/ch01_manifest.csv` 与同内容 JSON，包括 Line ID、角色、日语显示文字、实际朗读文字、情绪／强度／节奏提示、文件位置和每条朗读内容摘要值。

清单只收录 `dialogue`。不含 qixing、thought 或演出指令。无单独演技字段的条目使用该角色的本章默认基调，不把这些提示当成 Style-Bert-VITS2 保证支持的 API 参数。

用户生成后按 `game/audio/voice/<character>/<line_id>.ogg` 放置。游戏仅在文件存在时播放；未提供的条目保持静音，不生成替代语音，也不把缺失状态标成配音完成。修改文字后重新导出并对比摘要值，判断需要重录的条目。
