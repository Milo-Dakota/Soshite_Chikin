# 中文汉化指南

汉化输入仅限 `script_ja/ch01.yaml` 与本指南。禁止读取小说、故事总览、制作计划或历史会话。依据日语写出自然、认真的视觉小说汉化，不寻找或恢复中文原句，不增加剧情解释。

正式中文标题《无只因生还》；日文标题保留『そして〖只因｜チキン〗もいなくなった』。

梅川备代自报姓名的特殊读音「サスペンダーなし」意为未系背带。保留汉字姓名与误听笑点，让紧接着的对话自然衔接；不要解释梗，不必在中文字幕中重复日语注音。

## 语气与显示

中文为主字幕，日语为副字幕。中文使用简体中文标点。徐启星的独白自然、克制，避免补写第三人称旁白；少女起初礼貌而有戒备，情绪随日语变化；马皙随意健谈；郑局长有上司的威严与关心；梅川备代郑重礼貌。荒谬内容照样认真表达，不额外堆网络流行语。

每个非 direction 条目一一对应原有 Line ID，不合并、不删除、不重编号。演出指令和表演备注只用于理解语境，不翻进字幕。中文不使用 Ren'Py 标签或项目 Ruby 标记。日语台本与朗读文本保持不变。
