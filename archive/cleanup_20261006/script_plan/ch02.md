### ch02_sc01｜电视里的父亲与寻人启事

- scene_kind：main。
- narrative_pov：qixing。
- location：启星住处客厅 → 小区外街道（买早餐途中）。
- time：收留千夏后的清晨。
- characters：qixing、chinatsu、maxi（电话）；beidai 仅出现在电视演奏画面。
- story_purpose：用一起看电视建立暂住日常，确认千夏与备代的父女关系；寻人启事提供梅川千夏之名；引入本次音乐会的时间地点。
- mood：困倦、轻微尴尬和认真呈现的荒诞喜剧，尚未转为明确危险。
- visual_direction：先交代沙发、电视、玄关的空间关系。启星被演奏声叫醒，千夏已经看了一阵；不添加同床或同居恋爱暗示。电视采用屏幕内演出，区别于真实舞台。出门后由街道全景转到可读的启事，再回到启星接电话。
- music_direction：以电视内钢琴作为主要声音，室内不另叠同等响度 BGM；出门时结束电视声，可接 daily_calm。音乐不替观众嘲笑寻人启事。
- possible_sfx：轻量街道底声、手机铃声；接听时停止铃声，马皙说完即挂断。
- special_notes：保留二十年半、成名歌曲句式、全民制作人、两周半、中分／背带／只因她太美这组相互关联的梗。寻人启事内容必须能读到，不仅在制作备注出现；不直接使用生成图里的文字。马皙说“后天下午两点半、艾昆剧场”，不改写第一章“明天十点半”。原文“两种音乐会的票子”措辞可在日语中保持泛指拿到票，不自行落实为两张或两场；不扩写票务设定。
- beats：电视吵醒 → 父女关系与音乐人梗 → 出门买早餐 → 启事上的照片、姓名和荒诞全文 → 来电邀约、无机会推辞。
- source：L78—88；锚点为“昨夜是个平安夜”至“电话便被挂断了”。
- exit：挂断后的短停顿，接回家，不演出采购过程。

### ch02_sc02｜别问

- scene_kind：main。
- narrative_pov：qixing。
- location：启星住处玄关、客厅沙发旁。
- time：同一早晨，买早餐回来。
- characters：qixing、chinatsu；电视中的 beidai 为背景信息。
- story_purpose：再次确认左臂伤痕，引出启星的职业性观察与越界触碰；千夏的拒绝使温暖日常出现裂缝。
- mood：关切、惊吓、突然封闭。
- visual_direction：沿用上一场室内布局和电视方位；千夏抱膝。镜头先明确左上臂后侧青痕，再表现启星抓起她的手、她迅速抽回并蜷缩。动作使用明确的手部／双人构图，不用平移立绘冒充接触。厚袖不能透明：台本与服装设计时落实室内袖口或衣物位置，使观察成立，不能把伤处移到前臂或手背。
- music_direction：电视声延续但降低；提问与“别问”附近让背景退后，留下自然停顿，不用惊吓音效。
- possible_sfx：衣料轻响，可选；电视声音不压对白。
- special_notes：启星只能怀疑不像普通磕碰，不能断言施暴者。千夏没有在这里告知家庭侵犯，也不因他的警察习惯就识破职业。拒绝之后不新增追问、解释或和解。
- beats：回家仍在看电视 → 伤痕观察 → 下意识抓手 → 抽回 → 未完成的问题被拒绝。
- source：L89—93；锚点为“刚走到玄关”至“别问”，L93 为空行。
- exit：停在她的封闭反应，淡出后再进入数日的概括，不直接连成同一顿早餐。

### ch02_sc03｜玄关少了一双鞋

- scene_kind：main。
- narrative_pov：qixing。
- location：小区外街道 → 启星住处玄关、室内。
- time：音乐会当天上午；原文称此前“两天”低落、距音乐会六小时，不换算固定钟点或公历日期。
- characters：qixing；maxi 仅通过手机提醒出现；chinatsu 缺席。
- story_purpose：用撤掉的启事、提醒赴约的消息和空房，完成从照顾她的日常到失踪危机的转变。
- mood：牵挂迅速转为惊惶，随后强迫自己行动。
- visual_direction：以启星短内心概括千夏这两天的低落，不添加原作没有的两人日常。复用同一街段的启事已撤状态；手机提醒后，他考虑不能留她独自在家。切回已建立的玄关，空出的鞋位、无人回应的客厅形成缺失感。
- music_direction：低调日常底音在发现空房时淡出，再进入 mystery_low 或保留室内静默；避免一发现无人就用追凶高潮音乐。
- possible_sfx：门、脚步、稀疏室内底声；短信提示可有一次，不额外做连续警报或强心跳。
- special_notes：“被城管撤掉”原文带“似乎”，只能是启星的猜测；不展示城管实际撕启事。千夏不在、鞋不在是事实，被谁接走与是否安全尚未知。不添加绑架目击、告别纸条、定位软件、搜索家中证件或报警受理记录。
- beats：担心她持续低落 → 启事撤去 → 赴约提醒与陪伴顾虑 → 空玄关、空房 → 急促反应 → 决定去警局。
- source：L94—99；锚点为“这两天的千夏”至“既然这样……”。
- exit：明确行动意图后切警局；原文“本打算明天顺便处理”呈现为先前打算，不变成发现失踪后仍决定等一天。
