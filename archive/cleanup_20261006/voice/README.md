- 只录 `ja_spoken`，不录 `ja_display` 中的 Ruby 分隔符、角色名、演技备注。

- 徐启星对白和所有内心均不在清单中，无需配音。
- 单句朗读变化可通过 `spoken_sha256` 对比；演技变化也需人工确认是否重录。
