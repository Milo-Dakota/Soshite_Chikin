**把一部中文接龙小说，认真改编成日语视觉小说，再一本正经地汉化回来。**

## 关于这部作品

原作是中文接龙小说《无只因生还》。本项目希望呈现一种观感：它仿佛真的曾被某个日本厂商认真改编成 Galgame，随后又被中文汉化组汉化了回来。

中分、背带裤、艾昆剧院，以及接龙创作留下的荒诞转折，都属于故事本身。我们保留这些内容，以完整的角色设计、日语台词、配音和演出来认真对待它们。

> 越荒谬的原作内容，越应该认真制作。

日文标题中的 **「只因」写作汉字，读作「チキン」**。仓库使用 `〖只因｜チキン〗` 表示这种特殊注音；游戏内通过 Ruby 显示。这个读法也是作品标题的一部分。

## 第一章：パンと、家出少女

二月的杏城，休假中的徐启星走在去健身馆的路上。一名脸色苍白的少女拉住他的袖口，问他能不能把手里的面包给她。

一次短暂的相遇，延伸成一顿并不平静的午餐。

| 体验 | 内容 |
|---|---|
| 剧情形式 | 完全线性，无剧情选择 |
| 叙事视点 | 以徐启星为中心；特殊幕间明确切换视点 |
| 字幕 | 中文主字幕、日语副字幕，同时逐字显示 |
| 配音 | 其他角色使用日语配音；徐启星对白与所有内心不配音 |
| 画面 | 16:9，角色立绘、表情差分、背景与剧情 CG |
| 阅读功能 | 自动播放、快进、历史记录、存档与读档 |

本章包含 **6 场剧情、97 条双语正文、33 条角色语音和 34 张章节图片**。配乐、环境声与音效均已接入，钢琴演奏可点击跳过。

## 开始体验

**已有发行包：** 解压后运行包内对应平台的游戏启动程序，选择「开始故事」。

**从本仓库运行：**

1. 将仓库完整下载或克隆到本地，保留 `game/` 目录及其素材。
2. 使用 Ren'Py SDK 打开项目。本 Demo 使用过的引擎版本为 **Ren'Py 8.5.3**。
3. 启动游戏，从主菜单进入第一章。

运行现成工程无需先执行 `tools/` 中的制作脚本。读到「第一章・終」后，点击即可返回主菜单。

| 操作 | 按键 |
|---|---|
| 推进文字／点击跳过演奏 | 鼠标左键、Enter |
| 打开游戏菜单 | 鼠标右键、Esc |
| 回看 | 鼠标滚轮向上 |
| 隐藏文字界面 | H |
| 快进 | Ctrl |
| 切换全屏 | F |

自动播放、历史、存读档和设置也可从阅读底栏使用。音乐与语音音量可分别调整。

## 制作方式

项目使用 **Ren'Py** 作为运行与演出层，以日语正式台本作为文字源。图片通过生成工具辅助制作，角色语音按稳定台词 ID 交付并接入。

制作流程为：

```text
中文原作 → 全文理解与章节规划 → 当前章节日语台本
                                  ├─ 配音与演出
                                  ├─ 立绘、背景与 CG
                                  └─ 独立上下文中的中文汉化
                                             ↓
                                      Ren'Py 双语版本
```

改编遵循「剧情事实忠实，表现方式自由」。中文汉化依据日语台本与译名指南完成；普通场景的内心属于徐启星，镜头则可以自由展示人物与空间。

## 仓库结构

```text
game/          游戏脚本、图片、音频、字体与界面
source/        中文原作，作为剧情事实来源保留
script_ja/     日语正式台本
script_zh/     中文汉化文本
script_plan/   当前章节的场景计划与制作记录
voice/         录音台本、交付清单与配音原件
audio/         新音频原件入口，与 game/audio/ 同构
utilities/     可重复运行的本地工具（含音频导入）
assets/        角色参考、生成原图、提示词与素材索引
docs/          交付说明、设计文档、检查报告与历史归档
tools/         台本导出、演出生成与检查工具
```

制作资料包含剧透。想了解工程，可从以下入口开始：

- [制作资料导航](docs/README.md)
- [第一章当前交付](docs/ch01_handoff.md)
- [素材索引](assets/README.md)
- [制作工具](tools/README.md)

维护时先修改正式台本或演出源，再更新下游产物；Scene ID 和 Line ID 保持稳定。已发布版本的编译脚本随工程保留。
