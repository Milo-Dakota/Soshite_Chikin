# 第一章特殊演出约定

本章已完成。最终镜头在 scripts/staging/ch01/directions.json；对白取正式双语源，tools/build_ch01.py 生成章节。公共人物、声音与双语显示在 game/ch01_runtime.rpy，UI 在对应 game 文件。

- 对话采用两侧半身构图、水平中心／顶部锚点；表情不改变定位。启星／千夏街道和餐厅位置分开维护，马皙有左右等高等比例的独立位置。
- 备代使用公共区域构图；CG 独立，不能叠普通立绘。
- 章卡、阅读面板、历史／回退共用；第一章结束顺序进入第二章，无分支。
- 郑局来电四句在播放时加高通300 Hz＋低通3400 Hz，非电话及静音条目清除滤镜，不烘焙进原件。
- 徐启星及所有内心清除上一句 voice。音频仅从 audio 原件导入，不从旧 voice 交付副本覆盖。
