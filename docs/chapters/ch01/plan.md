# ch01 制作计划｜面包与离家少女

状态：本章制作已全部完成（用户于2026-10-06确认）。当前状态统一见 `docs/status.md`。

## 场景规划

### ch01_sc01｜街角的面包

- location：杏城住宅区通往健身馆的街道。
- time：二月白天，休假末期。
- characters：qixing、chinatsu（显示名尚为少女）。
- story_purpose：建立启星的职业与习惯，完成初遇、给予面包、淤青线索。
- mood：平静日常中有不协调的虚弱与急迫。
- visual_direction：街景建立空间，白色外衣进入；启星与少女可同框。面包交付以手部或双人构图表现；伤痕只作为短暂观察，不提前判断施暴者。
- music_direction：daily_calm，少女出现不立即切悬疑曲。
- possible_sfx：轻步声、衣袖摩擦；稀疏使用。
- special_notes：原文长羽绒服与可见手臂存在遮挡矛盾。本章不擅自把伤处改为手背：用启星短句保留“左臂后侧青痕”的观察，详细暴露动作不强造；淤青特写素材列为待解决，不用穿透衣袖的假画面。
- source：L3—12。

### ch01_sc02｜没带过的沐浴露

- location：健身馆、浴室隔间与更衣区。
- time：同日训练结束。
- characters：qixing、maxi、zheng（电话）。
- story_purpose：建立马皙的损友关系、音乐会引线和启星家庭疏离。
- mood：轻松互损，父母话题出现后沉静。
- visual_direction：浴室只取隔板、伸来的手和瓶子；人物换好衣服后进入常规对话。来电后目光与姿态由松弛转为回避。
- music_direction：沿用 daily_calm；询问是否回家时降低或淡出，保留停顿。
- possible_sfx：水声环境、手机铃声、柜门轻响。
- special_notes：不添加启星回拨父母或和解。郑局只电话出声，本章无需其立绘。
- source：L13—29。

### ch01_sc03｜被顺走的水（幕间）

- location：健身馆更衣区。
- time：紧接上一场，启星已离开。
- characters：maxi。
- story_purpose：回收沐浴露互损，留下具体演出消息。
- mood：短促喜剧，情绪不盖过家庭话题。
- visual_direction：显示幕间标识；马皙看手机、抬头、发现空座位和少了一瓶水。保持 external 视点，仅有可见行为与其说出口的话。
- music_direction：无须为短幕间重新起曲。
- possible_sfx：手机轻触。
- special_notes：“明天十点半”原样保留；不替换成后章另一条邀请的时间。
- source：L30—32。

### ch01_sc04｜没有拨出的电话

- location：杏城同一街区、路边。
- time：同日返回途中。
- characters：qixing、chinatsu（少女）。
- story_purpose：家人主题连接两人；水、搀扶、音乐压力及餐厅邀请推进信任。
- mood：迟疑转为关切。
- visual_direction：启星放下未拨出的手机；蹲坐的少女与少量面包；搀扶为双人动作画面，避免立绘水平移动冒充触碰。
- music_direction：warm 或恢复轻柔 daily_calm，在她讲家境时保持克制。
- possible_sfx：瓶子轻响、脚步。
- special_notes：千夏只说十七岁、音乐世家与练习压力，不提前说父亲侵犯；双方尚未交换姓名。
- source：L33—44。

### ch01_sc05｜钢琴家的名字

- location：有临街窗和钢琴的西餐厅。
- time：同日用餐时。
- characters：qixing、chinatsu、beidai、无名随行者（无对白）。
- story_purpose：姓名与职业误会、自尊与音乐热情、父亲登场、离家真实压力的暗示，最后确立收留决定。
- mood：尴尬转为轻松，骤然紧张，父亲离开后短暂安全。
- visual_direction：相对而坐；少女模仿拉琴；透窗看黑色礼宾车与棕色背带裤随行者；备代郑重鞠躬、坐下演奏。少女未被找到，不补“买通店员”等解释。
- music_direction：餐厅平稳配乐；备代开演时让环境音乐让位于画内钢琴，结束后先留短静默。
- possible_sfx：餐具、开门、衣料。
- special_notes：姓名特殊读法属于本地化手段；汉字姓名保留。启星不明确否认警察身份。原文 L71 同一行含不同人发言，按“千夏答应、启星买单”的上下文拆分。
- source：L45—71。

### ch01_sc06｜二十岁的大叔

- location：餐厅外回家路上。
- time：同日稍后，不凭空跳到夕阳。
- characters：qixing、chinatsu。
- story_purpose：回收流浪猫式相遇，以自然打趣和启星年龄收束本章。
- mood：温暖、稍显笨拙。
- visual_direction：两人一前一后，千夏稍靠近；启星侧头藏住笑意，随后因“大叔”停步抗议。
- music_direction：warm 延续至章末淡出。
- possible_sfx：轻脚步。
- special_notes：终点在“我才二十岁”，不提前演出同居翌晨。
- source：L72—76。
