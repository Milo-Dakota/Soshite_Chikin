# 公共菜单

主菜单使用剧院背景、正式标题 Ruby、中文副题及克制的暗金／深蓝配色，延续2010—2016年日式PC视觉小说气质。

“开始故事”从故事起点顺序推进，章节入口跳到对应章节；按钮集合及可达范围以菜单和构建入口代码为准，不在文档复述最新制作边界。章节入口不构成剧情选择。

维护源为 game/ch_main_menu.rpy、game/ch_menu_pages.rpy、game/screens.rpy；关于页版本读取 game/options.rpy，不在文档另维护版本号。存读档、设置、历史、帮助等沿用当前布局及功能。

修改后检查按钮动作、返回路径、设置持久化与存读档体验；只改 UI 时不重读原小说或全章台本。
