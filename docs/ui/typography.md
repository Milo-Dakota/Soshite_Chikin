# 字体与阅读规格

以下为当前实装规格，修改 UI 时按需核对对应运行样式。

| 用途 | 字体 | 字号 |
|---|---|---|
| 中文主字幕／内心 | SourceHanSerifSC-Medium.otf | 36 |
| 日语副字幕 | SourceHanSerifJP-Medium.otf | 24 |
| 中文姓名 | SourceHanSerifSC-Medium.otf | 26 |
| 主标题／章卡 | ShipporiMincho-SemiBold.ttf | 主菜单 49、章卡 48 |
| 章卡副标题 | SourceHanSerifSC-Medium.otf | 29 |
| 菜单与中文 UI | SourceHanSansSC-Regular.otf | 按各页面配置；演奏跳过提示 22 |
| 日语注音 | SourceHanSansJP-Regular.otf | 副字幕 13、标题 19 |

字体文件在 `game/fonts/`。中文、日文同时开始各自逐字显示，历史保留双方文字与日文字体。阅读面板 1776×350，姓名在一体式页眉中，正文宽度 1648；布局详见 `docs/ui/reading_panel.md`。
