# 双语阅读面板

使用一体式页眉；姓名与正文左对齐，姓名后短暗金线。中文主字幕比日语副字幕醒目，内心隐藏姓名与装饰，正文位置固定。

底板为 game/gui/reading_panel_a.svg，深蓝文字区域与上沿渐变；底栏共用底板。quick_menu 仅在 ch_say 存在时显示，隐藏文本同时隐藏底栏。

历史保留两种文字及日文字体。检查长注音、双语溢出、内心／对白切换、窗口缩放与隐藏文本时的底栏行为。

面板、文字宽度与角色样式读取 `game/ch01_runtime.rpy` 中的 `ch_say` 及相关样式；底栏读取 `game/ch_reading_bar.rpy`，其他公共界面读取 `game/screens.rpy`。精确尺寸、位置和字号只在这些实现中维护，本文件不另存数值副本。
