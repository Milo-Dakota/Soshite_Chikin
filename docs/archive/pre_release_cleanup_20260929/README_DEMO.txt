『そして〖只因｜チキン〗もいなくなった』
Chapter 1 Bilingual Demo 0.3

第一章「パンと、家出少女」。完全线性，无剧情选项。

工程试玩：用 Ren'Py SDK 打开 soshite_chikin 项目，点击启动游戏，再从主菜单开始。
范围：面包初遇 → 健身馆 → 马皙幕间 → 路边再会 → 餐厅 → 一起回家。
出现「第一章・終」后点击返回主菜单，即已读完本 Demo。

操作：鼠标左键／Enter 推进，右键／Esc 打开游戏菜单。
鼠标滚轮向上回看，H 隐藏文字框，Ctrl 快进，F 切换全屏。
存档、读档、历史、自动播放均沿用 Ren'Py 菜单。
本次更新调整了演出，完整验收建议从“开始”重读。

音频为可选文件。未提供时相应段落静音，钢琴演出采用较短展示；
补入钢琴音频后展示约 18 秒，可点击推进。
正文为中文主字幕、日语副字幕；配音仍使用日语。徐启星对白与所有内心没有配音，不是漏录。

音频交付给制作者的说明在工程 docs/ch01_audio.md，
逐句录音文本与保存路径在 voice/ch01_recording.md。
上述制作文件不包含在 SDK 打包的玩家发行版内。
