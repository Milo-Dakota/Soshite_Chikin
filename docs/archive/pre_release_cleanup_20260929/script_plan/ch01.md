## 场景规划

### ch01_sc01｜街角的面包

- location：杏城住宅区通往健身馆的街道。
- time：二月白天，休假末期。
- characters：qixing、chinatsu（显示名尚为少女）。
- story_purpose：建立启星的职业与习惯，完成初遇、给予面包、淤青线索。
- mood：平静日常中有不协调的虚弱与急迫。
- visual_direction：街景建立空间，白色外衣进入；启星与少女可同框。面包交付以手部或双人构图表现；伤痕只作为短暂观察，不提前判断施暴者。
- music_direction：daily_calm，少女出现不立即切悬疑曲。
- possible_sfx：轻步声、衣袖摩擦；稀疏使用。
- special_notes：原文长羽绒服与可见手臂存在遮挡矛盾。本章不擅自把伤处改为手背：用启星短句保留“左臂后侧青痕”的观察，详细暴露动作不强造；淤青特写素材列为待解决，不用穿透衣袖的假画面。
- source：L3—12。
