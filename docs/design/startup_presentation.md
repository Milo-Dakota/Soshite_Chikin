# 启动演出与厂牌朗读

> 当前状态：2026-09-29 用户确认 Demo 完成并已发布。下文按制作过程保留设计细节；其中当时的“待验收”不代表当前待办。最新总交付见 `docs/ch01_handoff.md`。

实装位置：`game/ch_splash.rpy`。启动顺序：全白 0.4 秒 → 图案淡入 0.9 秒 → 停留 0.5 秒 → 厂牌名字淡入 0.8 秒 → 停留 3 秒 → 整体淡出回白色 → 声明页 → 点击进入主菜单。

声明页按用户确认原文显示，移除「本作品について」标题；日文 24 px、中文 19 px，正文从 Y=190 开始，点击提示独立位于底部。背景保持纯白。声明文字未改写。

## 用户制作的厂牌朗读

- 文件：`game/audio/sfx/chikurin_soft_call.ogg`
- 显示名称：竹林ソフト
- 日语朗读文本：ちくりんソフト
- 建议有效时长：1–2.5 秒，含结尾余韵尽量不超过 3 秒；不要在开头留长静音。
- 演绎：清晰、自然、带一点轻快的品牌招呼感；男女声均可，不需要添加背景音乐。
- 使用音效通道，因此跟随音效音量设置；不属于剧情角色语音清单。
- 文件存在时，与厂牌文字开始淡入同时播放一次；不存在时静默继续。文字淡入及后续停留合计约 3.8 秒，点击可缩短等待，离开厂牌页时淡出音效，避免串入声明页。
- 只放入上述文件即可自动接入。若成品明显长于 3 秒，再调整停留时间，不要求截断朗读来配合现有时长。

Agent 未获取、合成或试听音频。排版与时序待用户实际启动验收。

## 大厅登场动画

声明页点击后，0.8 秒淡入大厅背景，同时在 music 通道开始 `config.main_menu_music` 指定的 lobby 音乐，淡入 0.8 秒。背景完全出现后计时：1.2 秒开始主标题淡入与 10 像素上浮（持续 1 秒）；1.5 秒开始副标题淡入；2.4 秒开始主按钮淡入；2.6 秒开始底部按钮与版本字样淡入。按钮淡入持续 0.8 秒，3.5 秒交给完整主菜单。

动画只从 `splashscreen` 调用；返回主菜单、设置或存档页返回不重复播放。动画期间点击、空格／回车或 Esc 结束演出，动画里的按钮只结束演出，不执行游戏或菜单操作。音乐使用与主菜单相同的文件和通道，进入正式菜单时继续播放。使用同一菜单布局绘制动画，结束后不另加淡入，避免界面重播动画。

静态检查通过；用户负责实际启动确认过渡、跳过行为与音乐连续性。
