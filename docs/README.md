| 入口 | 用途 |
|---|---|
| [第一章交接](ch01_handoff.md) | 已发布内容、版本绑定、后续维护入口 |

| [发布记录](release/README.md) | 用户确认发布的状态与本地运行文件摘要 |

- `ch01/`：第一章声音、人物构图、表情、备代镜头和双语阅读稿。
- `design/`：字体、阅读面板、主菜单、功能页面、启动演出。
- `reports/`：机器检查与素材清单；其中 runtime_tested=false 表示 Agent 未运行引擎，不否定用户验收。
- `release/`：用户发布状态、整理时的工程摘要；不是发行包的替代物。
- `archive/`：历史建议及整理前快照，不作为待办或最新设计。旧路径按历史语境保留。

汉化输入边界不变：只提供日语台本、汉化指南及必要 ID／显示约束；本导航不意味着可以把交接、研究或归档资料放入汉化上下文。
