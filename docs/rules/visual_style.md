# 『そして〖只因｜チキン〗もいなくなった』视觉风格规范

创作规范沿用已完成两章的实际制作。具体布局以 `docs/ui/typography.md`、`docs/chapters/ch01/staging.md` 与 `docs/status.md` 为准。

本文件依据 `AGENTS.md`、故事总览和章节规划制定。适用目标为 2010—2016 年左右 PC 日式商业视觉小说的观感，而非把故事年代改为该时期。叙事仍发生在原作杏城；日语呈现不意味着日本地理、街道标志或社会身份的替换。

## 1. 核心方向

**二月都市的冷色环境、人物之间的暖光、剧院的克制华丽。**

整体使用精致的二维动画角色、清楚的轮廓、细腻但有节制的上色，以及带有绘画质感的日系动画背景。看起来应是一部认真制作的恋爱悬疑视觉小说，能自然容纳后段突然出现的北极冒险。

荒诞之处来自原作事实：备代的中分与背带裤、一本正经的自我介绍、星光求救、直升机冒险和保温杯决战。画面保持可信的空间、完整的人体和认真的表演，不使用表情包拼贴、真人脸贴图、低清素材或大字弹幕主动解释笑点。

统一尺度：角色可爱而有年龄感；男性与女性具有同等设计完成度；日常有温度，悬疑仍可辨认细节；受害与危险有重量，喜剧不消解伤害。

## 2. 画幅与画面层级

- 游戏逻辑画布沿用现有工程的 **1920×1080，16:9**。这是本项目制作基准，不在此阶段修改程序。
- 背景与 CG 交付至少满足该显示尺寸；原始生成图保留，不为凑尺寸拉伸人物。比例不符时先检查构图，再裁切、扩图或重做。
- 常规对话画面优先呈现角色眼神、双手和彼此距离，背景提供地点与气氛。关键动作需要额外构图，不能只靠反复晃动立绘代替。
- 下方约 350 像素预留双语文字区域。角色面部、关键道具和必须看懂的动作尽量位于上方；精确布局见第 8 节。
- 全画面保留约 5% 的边缘安全区。藏在线索边缘的物品也必须能在实际窗口尺寸辨认。
- 普通对话采用画面两侧的半身近景，原始角色立绘保留完整身体，游戏里按镜头裁切。保留角色头顶、眼线和肩线的高低关系，不以脚底贴合背景道路建立站立透视；关键身体动作使用既有 CG。

## 3. 线条、上色与材质

| 项目 | 统一规则 |
|---|---|
| 人物线条 | 干净、略有粗细变化；外轮廓稍重，鼻口与衣褶较轻；深棕或蓝黑线色，避免所有部位纯黑等粗描边 |
| 五官 | 日式动画比例，眼睛有清晰虹膜与少量高光；鼻口简洁，男性、少女与中年人的面部结构应可区分 |
| 人物上色 | 清楚的基础色与主要阴影块，局部柔和过渡；不用厚重油画笔触、皮肤写实毛孔或全身塑料高光 |
| 头发 | 以稳定发束和轮廓识别人物；高光成组，发丝细节为结构服务，不画成每根都发亮的金属丝 |
| 布料 | 棉、羽绒、针织、礼服与西装有不同褶皱和反光；衣服厚度、扣件、背带连接位置保持合理 |
| 背景 | 绘画式材质与稳定透视，细节由近及远递减；角色周围不能形成写实照片与动画立绘的明显割裂 |
| 光效 | 单一主要光源加适量环境反射；允许窗光、舞台边缘光，不叠加大面积光斑、粒子或发光轮廓 |

同一角色不同表情保持眼距、下颌、鼻口位置和头部大小。表情变化来自眉眼与嘴角，不把每个差分重新设计成另一张脸。

## 4. 色彩与光线

以下为制作选色起点，不是要求每张画面机械套用同一组颜色。肤色和人物固有色保持可辨认，环境变化通过光线和局部色温体现。

| 用途 | 基准色 | 使用方式 |
|---|---|---|
| 夜色、界面深底 | `#202735` 墨蓝灰 | 悬疑空间、文字底板；避免大面积纯黑吃掉层次 |
| 冬日环境 | `#94A5B2` 雾蓝灰 | 街道、窗外、远景与冷阴影 |
| 奶白与冬日亮部 | `#E8E3D9` 暖灰白 | 千夏外衣、室内亮面；保留阴影，不使用刺眼纯白 |
| 室内木色 | `#826B5A` 灰褐 | 餐厅、住宅与琴房，区别于饱和橙色滤镜 |
| 剧院装饰 | `#B39A68` 哑金 | 少量装饰、舞台边缘、标题细线 |
| 情绪强调 | `#8A4855` 暗玫瑰 | 礼服细节、界面选中状态或极少量装饰，不满屏铺红 |
| 正文亮色 | `#F3EFE7` 米白 | 深色对话框上的主要文字 |

场景色温原则：

- **日常街道**：二月的淡冷自然光，适度暖阳。原文说春来得早，不自动添加大雪、盛放樱花或典型日本校园街道。
- **餐厅与启星住处**：温暖局部光源，阴影仍带冷灰。温暖来自人物获得短暂安全，不靠每次亲近都出现粉色光晕。
- **梅川宅与剧院**：木色、深色织物、哑金和局部亮面，空间端正。备代初次登场不预先打上“反派红光”。
- **命案调查**：偏冷、降低环境明度，但人物手、证件、假发和通路应可读。黑暗用于限制信息，不用于掩盖制作缺陷。
- **北极**：冰蓝、灰白与室内少量暖光，延续同样的线条、角色上色和材质体系。不要变成写实灾难电影海报。
- **尾声舞台**：克制的暖白聚光与深色观众席，人物固有色清晰；呼应前面的剧院，而非换成另一套偶像手游舞台。

## 5. 人物设计：事实与美术选择

下列“美术选择”是本项目的初始设计方向，原文没有规定的部分不写入剧情事实。正式 Reference 生成时可在这一方向内微调；选定后记录最终样貌与版本，后续素材依照 Reference 制作，不临时换脸。

### 徐启星

- **原作约束**：二十岁，训练有素，英俊但仍有少年气；初登场穿大衣，后续有黑色警服；是完整可见的主角。
- **美术选择**：近黑色短发，自然侧分，额前少量发束；深灰棕眼睛，眉形清楚，下颌偏利落但不显中年。身形精干、肩背挺直，不画成夸张健美体型。
- **初登场衣着方向**：深炭灰大衣、低饱和内搭与长裤，整洁而实用；与千夏米白长外套形成深浅对照。不添加原文未给出的勋章、战术装备或显眼奢侈品牌。
- **相对比例**：常态约 7.5 头身，明显高于千夏，初步身高差约半个头至三分之二个头；具体比例由并排 Reference 固定，不在台本补写身高数字。
- **表演重点**：办案时专注，日常放松时仍有拘谨；害羞体现在目光与嘴角，不能统一用遮眼男主模板代替他的面部。

### 梅川千夏

- **原作约束**：十七岁，长发；初见虚弱、脸色苍白，米白色羽绒外衣长至小腿；左上臂后侧有淤青。后续礼服与尾声黑色长裙按当章原文制作。
- **美术选择**：深栗棕长直发，柔和的刘海和颊侧发束；暖棕眼睛、略窄椭圆脸，少女感明确。约 7 头身，身形纤细但不是病态骨瘦；与启星同框时保持稳定身高差。
- **初登场衣着方向**：奶白长羽绒服、保暖下装和简洁鞋履；内搭细节留到本章服装 Reference 确定，不添加标志性发饰、校徽或与剧情无关的身份暗示。
- **表演重点**：初见缺乏血色、目光戒备；吃饭后气色稍好，有自尊和活力。恐惧、羞涩与开心必须可区分，不能所有表情都以红脸处理。
- **连续性重点**：左臂是人物自身左侧，不能为方便构图镜像成右臂。厚外套遮挡淤青的问题在具体镜头中解决，例如前臂伸出时袖口上移是否足以呈现；若不成立，另作不改变伤处位置的局部镜头安排，不画“透过袖子看见淤青”。

### 梅川备代

- **原作约束**：有成年子女的父亲，知名钢琴家；中分、背带裤、浮夸正式登场。餐厅随行者穿棕色背带裤；后续琴房明确灰色裤装与白色背带，不把不同场合强行合并成唯一服装。
- **美术选择**：成熟中年男性，梳理精致的中分，衣料与鞋履讲究，轮廓端正；餐厅可采用棕灰服装与整洁浅色衬衣。用户于 2026-09-28 明确指定头发为完全无饱和度的中性灰：只保留灰阶明暗，不带棕色或其他色偏，包括暖色室内镜头。后续以 `assets/reference/beidai/beidai_casual_v2.png` 为发色及面部参考，不再沿用棕发初稿。灰色中分假发作为案件道具另行遵循原文，此美术选择不新增天然发色或假发身份的剧情结论。
- **表演重点**：登场的可笑之处来自郑重姿态和夸张礼节；面部保持商业角色画法。阴暗行为发生时用表情、距离和压迫构图呈现，不能一开始就画成怪物，也不能将伤害美化为魅力。

### 其余角色

马皙的设计方向为松弛、略随意的艺术工作者，与启星的整洁克制相区别；具体发型服装在需要其 Reference 时定。郑局保留年逾五十的年龄感；若当章仅电话出场，不因此提前制作其全套立绘。其余角色到实际章节再设计，不在此阶段补齐全员设定。

库子与备代的相似面容、协子与千夏的相似外貌属于后续必须维持的关系约束；相似不等于复制同一张脸，且不能在身份应当存疑的镜头中用独有标记提前给出答案。

## 6. 背景与空间连续性

- 杏城采用原作容许的当代城市空间；招牌文字单独制作，不让生成图中的乱码成为正式内容。避免随意出现东京地标、日式警署标识或地域明确的车牌。
- 先建立地点主视角，再做必要的角度与时段变化；同一地点的门窗、钢琴位置、座位与出入口保持可对应。
- 餐厅要能支持隔窗看到路边礼宾车、人物对坐、备代进入并演奏的空间关系。不要先生成互相矛盾的好看背景，再强行拼在一起。
- 健身馆兼顾器械区、更衣环境与浴室的生活感，日常对话以面部、储物柜、沐浴用品等构图承载；不以身体展示作为该场景的重点。
- 艾昆剧院是跨章节回访的核心地点；制作时保存舞台、观众席、侧门等相对位置。首次演出、调查和尾声靠灯光及局部布置变化表达，不换建筑。
- 背景中的物品不能擅自解释未解谜团；例如不能画出已证实的星光发射装置、秘密逃生通道或遗体替身设备。

这里只规定连续性原则，详细背景数量、道具清单与镜头到当前 Chapter 台本稳定后确定。

## 7. 镜头与表演

Narrative POV 为徐启星中心，Visual POV 自由。可以正面展示启星、双人同框、越肩、中远景和俯仰角；画面展示不等于启星获得画面里所有信息。

| 情境 | 镜头和表演选择 |
|---|---|
| 日常对话 | 稳定中景、清楚视线关系；用少量姿态和表情变化维持节奏，不每句话切一次镜头 |
| 陌生人与逐渐信任 | 从保留距离的双人构图过渡到较近的同框；通过站位、空隙与手部动作体现关系 |
| 羞涩与喜剧 | 留出反应时间，用停顿、移开目光、轻微皱眉表达；不用 Q 版变形、汗滴爆屏或 meme 音画 |
| 备代登场 | 端正构图、完整仪态与音乐人排场；中分和背带清晰可见，幽默由他认真完成荒谬行为产生 |
| 调查与线索 | 先交代人物和物件位置，再给必要特写；证件文字等关键信息应清楚，不能全靠对白补图 |
| 恐惧与家庭伤害 | 以退缩、僵硬的手、封闭空间和危险距离呈现；保留受害者拒绝与恐惧，不用裸露、性化身体特写或浪漫滤镜 |
| 暴力与伤亡 | 强调动作结果、人物反应与后果；血迹数量等剧情线索应保留，避免用黑屏掩去必要事实，也不以解剖细节作为观赏重点 |
| 动作高潮 | 先有可理解的方位，关键招式使用有针对性的画面；局部短震动辅助冲击，不持续摇屏影响阅读 |

普通转场以约 0.2—0.5 秒淡入淡出作为初始节奏；明确时间或地点跳跃再采用较长过渡。数值只是调试起点，最终随台词和音画调整。避免频繁白闪、持续闪烁与自动跳过玩家尚未读完的文本。

特殊视点以明确的地点／视点提示及转场区分；不只依赖颜色，因为颜色无法单独说明谁知道哪些信息。章节标题卡保持统一，不提前写未完成的正式日语标题。

## 8. 当前双语界面与标题

游戏1920×1080，中文主字幕36 px／日语副字幕24 px，姓名26 px，一体式阅读面板1776×350，正文宽1648。精确字体和排版见 docs/ui/typography.md 与 docs/ui/reading_panel.md。

正式标题保持「只因」与「チキン」Ruby。需要可读文字的启事、票面和 UI 使用台本与排版实现，不依赖生成图猜字。检查缩放窗口、长注音、角色姓名和重要画面不被正文遮住。

## 9. 图片制作与一致性

1. 先核对复用；角色／服装采用 assets/reference 中选用版本。当前立绘多为1024×1536，背景／CG 多为1672×941；保持已确认比例，不为满足旧目标强制放大重做。
2. 新角色 Reference 明确脸型、发型、发色、眼睛、年龄感、身形比例、常用衣服、配色；在大量正式出图前确定。
3. 每套立绘固定画布、人物大小、头部位置、衣服与姿态。表情基于基础图局部修改，透明底须真实透明，棋盘格不是透明。
4. BG／CG 按实际镜头适配16:9，保持光向、透视、空间连续性；清晰度通过实际缩放检查，不能将放大称为更高原生精度。
5. 有左右差异的伤痕／服装／道具不能水平翻转偷换。当前章节特殊要求见对应 assets.md。
6. 提示词、参考关系、选用原件和运行路径记录到 assets/records，不在章节文档重复整张文件表；历史版本归档，替换时更新引用。

## 10. 变更后的画面检查

人物身份和比例稳定，差分不跳动，透明边缘干净；背景和角色光向协调；中分与背带梗认真呈现；关键动作与线索清楚；双语／Ruby 不溢出，缩放仍可读。必要时在实际游戏中检查。
