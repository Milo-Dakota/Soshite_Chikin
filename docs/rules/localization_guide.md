# 中文汉化指南

汉化输入仅限当前章节的 `scripts/ja/chXX.yaml`、理解它所必需的日语上下文与本指南。禁止读取小说、故事总览、制作计划或历史会话。使用未读取原文的独立上下文；依据日语写出自然、认真的视觉小说汉化，不寻找或恢复中文原句，不增加剧情解释。

## 语气与显示

中文为主字幕，日语为副字幕。中文使用简体中文标点。徐启星的独白自然、克制，避免补写第三人称旁白；少女起初礼貌而有戒备，情绪随日语变化；马皙随意健谈；郑局长有上司的威严与关心；梅川备代郑重礼貌。荒谬内容照样认真表达，不额外堆网络流行语。

每个非 direction 条目一一对应原有 Line ID，不合并、不删除、不重编号。演出指令和表演备注只用于理解语境，不翻进字幕。中文不使用 Ren'Py 标签或项目 Ruby 标记。日语台本与朗读文本保持不变。

## 第二章适用说明

- 本章输入为 `scripts/ja/ch02.yaml`。`dialogue`、`protagonist_dialogue`、`thought`、`document_text` 均须翻译，`direction` 不进入 `lines`。书面文字包含署名，保留为书面文字，不变成配音对白。
- main 的内心属于徐启星；两段千夏视点幕间的内心属于千夏；external 幕间没有内心。根据说话者与视点保持人称，镜头说明不转成第三人称小说旁白。
- 千夏对父亲的礼貌、拒绝与恐惧，以及备代从假关心到粗暴支配的变化，都以日语为准；不将拒绝译成撒娇。匿名来电者保持匿名。
- Ruby 通常取汉字表记，专名按上表统一；在句中承担普通词义的 Ruby 按日语含义自然处理，不把特殊注音符号带进中文。标题约定不变。
- 字号与可用宽度由任务提供的显示限制确定；优先自然、清楚的短句。不为长度硬删信息、不拆改 ID，可能过长的条目另行标记供实际排版核验；字符数检查不等于游戏内布局通过。
- 输出 `scripts/zh/ch02.json`，结构为 `chapter_id`、`source_ja_sha256`、`chapter_title_zh`、`lines`（Line ID 到中文字符串的映射）。章节标题按日语标题翻译，不读取中文制作计划取名。SHA-256 对应实际日语文件字节。
