# 『そして〖只因｜チキン〗もいなくなった』

《无只因生还》的 Ren'Py 线性视觉小说。日语角色配音，中文主字幕与日语副字幕；徐启星对白及内心无配音。

用 Ren'Py 启动器打开此工程运行游戏；制作进度统一见 [当前状态](docs/status.md)。

- Agent 从 [AGENTS.md](AGENTS.md) 开始，按任务读取所需资料。
- 制作流程见 [workflow](docs/workflow.md)，章节状态见 [status](docs/status.md)。
- 美术原件在 assets，游戏运行资源在 game。
- 音频原件放 audio，双击根目录 import_audio.cmd；[使用说明](tools/audio_import/README.md)。
- 给人类的少量交接直接在聊天完成，批量清单才放 handoff，不默认生成预览网页。
- 工具使用 [统一入口](tools/README.md)。.venv 保存 Python 环境；.build 只保存当前机器清单与工具记录。
